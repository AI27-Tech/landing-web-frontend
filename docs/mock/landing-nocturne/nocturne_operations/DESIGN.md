# Nocturne Operations — AI27

Dark-first data + security brand. No absolute black; use tonal slate surfaces.

## Color
- Primary / accent: #7C9DF0 (muted periwinkle). On-primary text: #0E1117.
- Global canvas (page background): #0E1117.
- Surface / panels: #1C222E. Raised / hovered cards: #242B3A. Recessed: #161B24.
- Borders: hairline #2D3748; strong #374151.
- Text: #E2E8F0 primary; #94A3B8 muted labels; #D1D5DB supporting. Never pure white.
- Status: success #6EE7B7, warning #FCD34D, danger #FCA5A5 (low saturation).

## Typography
- Inter everywhere. Tabular figures for any numbers/metrics/telemetry.
- Display 32/40 700 tracking -0.02em. Headline 24/32 600. Body 13-15 400. Labels uppercase 11px 600 tracking 0.05em.

## Shape & feel
- Low curvature: 4px base radius. Structured, precise, engineered.
- Spacious but data-dense: comfortable padding around tight, information-rich modules.
- Cool-tinted soft shadows, subtle. Sleek, high-tech, trustworthy.
